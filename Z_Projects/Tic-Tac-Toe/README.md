Tic-Tac-Toe 🎮

My first JavaScript project, built while learning JavaScript through the Apna College JavaScript Full Course playlist.

📌 About the Project

This is a simple Tic-Tac-Toe game built using HTML, CSS, and JavaScript. Two players take turns placing O and X on a 3 × 3 board. The game checks for a winner or a draw.

✨ Features

* Interactive 3 × 3 game board
* Two-player gameplay
* Automatic winner detection
* Draw detection
* New Game button
* Reset Game button
* Custom styling using CSS

🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

📚 What I Learned

* DOM manipulation
* Event listeners
* JavaScript functions
* Conditional statements
* Arrays and loops
* Implementing game logic
* Detecting winning patterns

▶️ How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open index.html in your web browser.
4. Start playing!
